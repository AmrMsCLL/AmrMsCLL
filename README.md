### About

Computer Science & AI graduate from **FCAI, Cairo University**, now building document-intelligence
software at **Syntheia** — a platform that ingests, parses, segments and compares legal contracts,
then puts the results in front of lawyers inside the web app and Microsoft Office.

I work across the whole stack, which in practice means a normal week touches a TypeScript API, a
React front end, a Python ML service and a Helm chart. I like the layer where those meet.

```
  backend    NestJS · Prisma · PostgreSQL · Redis · GraphQL · SAML/OAuth
  frontend   React · Redux Toolkit · MUI · Tailwind · Vite · Playwright
  ml         PyTorch · Transformers · spaCy · Milvus · scikit-learn · Celery
  platform   Docker · Kubernetes · Helm · Terraform · AWS · Azure · SonarQube
  office     Office.js add-ins for Word & Outlook
```

---

### Currently

- **Document ingestion pipeline** — a fan-out of Python services (OCR, DOCX and PDF extraction,
  file conversion, clause segmentation) coordinated through Celery and Redis.
- **Semantic clause comparison** — sentence-transformer embeddings in Milvus, so a clause in one
  contract can be matched against a playbook of thousands.
- **Smart Drafter & Outlook add-ins** — Office.js task panes that bring redlining and review into
  Word and Outlook instead of asking anyone to leave them.
- **Multi-tenant infrastructure** — Terraform-managed AWS and Azure estates with per-tenant Helm
  releases and blue/green cutovers.
